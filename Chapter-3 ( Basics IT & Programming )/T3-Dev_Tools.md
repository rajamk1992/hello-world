# Development Tools Overview

## 🔹 Version Control & Code Hosting

- **GitHub** – Git-based code hosting, pull requests, collaboration.
- **GitLab** – Git repository + built-in CI/CD.
- **Bitbucket** – Git hosting, integrates with Jira.

---

## 🔹 CI/CD Tools

- **Jenkins** – Automates build and deployment pipelines.
- **GitHub Actions** – CI/CD directly inside GitHub.
- **CircleCI** – Cloud-based automation tool.

---

## 🔹 Containerization & Deployment

- **Docker** – Packages application with dependencies into containers.
- **Kubernetes** – Manages containerized applications at scale.
- **Nginx** – Web server and reverse proxy.

---

## 🔹 IDEs & Code Editors

- **Visual Studio Code** – Lightweight, highly popular editor.
- **IntelliJ IDEA** – Popular for Java development.
- **Eclipse** – Widely used IDE for Java and enterprise apps.

---

## 🔹 Build & Package Tools

- **npm** – JavaScript package manager.
- **Maven** – Dependency management & build tool.
- **Gradle** – Modern build tool (Java, Android).

---

## 🔹 Database Tools

- **MySQL Workbench** – GUI for MySQL.
- **pgAdmin** – PostgreSQL management tool.
- **MongoDB Compass** – GUI for MongoDB.


## 1. Git

-   Distributed version control system
-   Tracks code changes
-   Supports branching and merging

## 2. GitHub

-   Cloud-based Git repository hosting 
-   Collaboration using pull requests
-   CI/CD with GitHub Actions

## 3. Jira

-   Project management and issue tracking
-   Supports Agile (Scrum, Kanban)
-   Sprint and backlog management

## 4. Postman

-   API testing tool
-   Supports GET, POST, PUT, DELETE requests
-   Automated API collections

## 5. Visual Studio Code

-   Popular lightweight code editor
-   Extensions support multiple languages
-   Integrated Git support

## 6. Docker

-   Containerization platform
-   Packages application with dependencies
-   Ensures environment consistency

## 7. Jenkins

-   CI/CD automation tool
-   Automates build, test, and deployment pipelines

## 8. npm

-   Node package manager
-   Manages JavaScript dependencies
-   Runs scripts and builds

## 9. Kubernetes

-   Container orchestration platform
-   Manages and scales containerized applications
