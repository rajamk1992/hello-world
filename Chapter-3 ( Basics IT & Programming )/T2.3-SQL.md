# SQL

# 1️⃣ Introduction to Database

## What is a Database?

A Database is an organized collection of data that can be easily
accessed, managed, and updated.

### Real-Time Examples:

-   Banking system stores customer accounts
-   College system stores student details
-   E-commerce stores product and order details

------------------------------------------------------------------------

# 2️⃣ What is DBMS?

DBMS (Database Management System) is software used to manage databases.

Examples: - MySQL - PostgreSQL - Oracle - SQL Server

------------------------------------------------------------------------

# 3️⃣ What is SQL?

SQL (Structured Query Language) is used to communicate with databases.

SQL is used to: - Create data - Read data - Update data - Delete data

These operations are called CRUD operations.

------------------------------------------------------------------------

# 4️⃣ Basic SQL Commands

## Sample Table: students

  id   name    age   city
  ---- ------- ----- ---------
  1    Ravi    20    Chennai
  2    Meena   22    Madurai
  3    Arjun   21    Salem

## 🔹 CREATE TABLE

``` sql
CREATE TABLE students (
  id INT PRIMARY KEY,
  name VARCHAR(50),
  age INT,
  city VARCHAR(50)
);
```

------------------------------------------------------------------------

## 🔹 INSERT

``` sql
INSERT INTO students (id, name, age, city)
VALUES (4, 'Kumar', 23, 'Coimbatore');
```

------------------------------------------------------------------------

## 🔹 SELECT

``` sql
SELECT * FROM students;
```

Select specific columns:

``` sql
SELECT name, age FROM students;
```

------------------------------------------------------------------------

## 🔹 WHERE (Filtering)

``` sql
SELECT * FROM students
WHERE age > 20;
```

------------------------------------------------------------------------

## 🔹 UPDATE

``` sql
UPDATE students
SET city = 'Trichy'
WHERE id = 1;
```

------------------------------------------------------------------------

## 🔹 DELETE

``` sql
DELETE FROM students
WHERE id = 3;
```

------------------------------------------------------------------------

## 🔹 ORDER BY

``` sql
SELECT * FROM students
ORDER BY age DESC;
```

------------------------------------------------------------------------

## 🔹 COUNT

``` sql
SELECT COUNT(*) FROM students;
```

# 5️⃣ JOIN Queries (Very Important for Interviews)

## Real-Time Scenario: College Management System

### Table 1: students

  student_id   name
  ------------ -------
  1            Ravi
  2            Meena
  3            Arjun

### Table 2: marks

  student_id   subject   marks
  ------------ --------- -------
  1            Maths     90
  2            Science   85
  4            English   70

------------------------------------------------------------------------

## 🔹 INNER JOIN

Returns only matching records.

``` sql
SELECT students.name, marks.subject, marks.marks
FROM students
INNER JOIN marks
ON students.student_id = marks.student_id;
```

Explanation: Only students who have marks will appear.

------------------------------------------------------------------------

## 🔹 LEFT JOIN

Returns all records from left table.

``` sql
SELECT students.name, marks.subject, marks.marks
FROM students
LEFT JOIN marks
ON students.student_id = marks.student_id;
```

Explanation: All students appear. If no marks, NULL will be shown.

------------------------------------------------------------------------

## 🔹 RIGHT JOIN

Returns all records from right table.

``` sql
SELECT students.name, marks.subject, marks.marks
FROM students
RIGHT JOIN marks
ON students.student_id = marks.student_id;
```

Explanation: All marks appear even if student not found.

------------------------------------------------------------------------

## 🔹 FULL JOIN

Returns all records from both tables.

``` sql
SELECT students.name, marks.subject, marks.marks
FROM students
FULL JOIN marks
ON students.student_id = marks.student_id;
```

------------------------------------------------------------------------

# 6️⃣ Difference Between JOIN Types

  JOIN Type    Returns
  ------------ ---------------------------
  INNER JOIN   Matching records only
  LEFT JOIN    All left + matching right
  RIGHT JOIN   All right + matching left
  FULL JOIN    All records from both
