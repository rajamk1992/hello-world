## Types of Language

### Programming Language

-   Programming languages are a set of instructions or code which tells
    a computer what it needs to do.
-   Examples: Java, C, C++, C#
-   Mostly used to make software or drivers.

### Scripting Language

-   Interpreted language -- runs or executes inside another program.
-   Used to perform certain tasks.
-   No compiler required.
-   Mostly used to create websites.
-   Examples: JavaScript, PHP, Perl, Python

### Markup Language

-   Prepares structure for the data or design of a page.
-   Does not include logic or algorithms.
-   Controls presentation and formatting of data.
-   Examples: HTML, XML

# HTML, CSS, JavaScript

## HTML (Hyper Text Markup Language)

-   Describes the structure of a web page.
-   Consists of elements that tell the browser how to display content.

``` html
<!DOCTYPE html>
<html>
<head>
<title>Webpage</title>
</head>
<body>
<h1>Heading</h1>
<p>Paragraph</p>
</body>
</html>
```

### Common Tags

-   `<h1>`
-   `<p>`
-   `<br>`
-   `<a href="https://www.google.com">Link</a>`
-   `<img src="image.jpg" alt="Person image">`

### Formatting Elements

-   `<b>` -- Bold text
-   `<strong>` -- Important text
-   `<i>` -- Italic text
-   `<em>` -- Emphasized text
-   `<mark>` -- Marked text

## CSS (Cascading Style Sheets)

-   Used to style HTML elements.
-   A selector points to an HTML element.

``` css
p {
  color: red;
  text-align: center;
}

.para {
  color: blue;
}

#para {
  color: white;
}
```

### Ways to Insert CSS

-   External CSS
-   Internal CSS
-   Inline CSS

### Common Properties

-   `background-color`
-   `border-style`
-   `margin`
-   `padding`

## JavaScript

-   Programs the behavior of web pages.
-   Uses DOM methods like `getElementById()`.
-   Objects: document, window, console

``` html
<script src="myScript.js"></script>
```

``` javascript
document.getElementById("myElement").innerHTML = "Hello JavaScript";
```

## JavaScript Variables

-   `var` -- Can be redeclared
-   `let` -- Block scope
-   `const` -- Cannot be changed

``` javascript
const PI = 3.14159;
let x = 5;
let y = 6;
let z = x + y;
```
