# Server – Notes

## What is a Server?

A **server** is a computer system or software that provides services, data, or resources  
to other computers (called **clients**) through a network such as the Internet or a local network.

It follows the **Client–Server Model**:
- Client sends a request  
- Server receives, processes, and sends a response  

---

## Types of Servers

1. **Web Server** – Hosts websites  
   _Examples: Apache, Nginx, IIS_
2. **Application Server** – Runs applications and business logic
3. **Database Server** – Stores and manages data  
   _Examples: MySQL, Oracle, SQL Server_
4. **File Server** – Stores and shares files
5. **Mail Server** – Manages email services

---

## Functions of a Server

- Receives and processes client requests  
- Stores and manages data  
- Provides security and access control  
- Handles multiple users at the same
