# SDLC -- Seminar Presentation Notes

## What is SDLC?

Software Development Life Cycle (SDLC) is a structured process used to
design, develop, test, and maintain software.

> Idea → Plan → Build → Test → Release → Maintain

------------------------------------------------------------------------

## SDLC Flow Diagram

    Requirement → Planning → Design → Development → Testing → Deployment → Maintenance

------------------------------------------------------------------------

## 1. Requirement Gathering

-   Understand client needs
-   Identify system features
-   Prepare requirement documents

Output: - BRD / FRD

------------------------------------------------------------------------

## 2. Planning

-   Time estimation
-   Cost estimation
-   Team allocation
-   Technology selection

Output: - Project plan

------------------------------------------------------------------------

## 3. System Design

### High-Level Design (HLD)

-   Architecture design
-   Modules breakdown
-   Database structure

### Low-Level Design (LLD)

-   API flow
-   Logic design
-   Table structure

------------------------------------------------------------------------

## 4. Development (Coding)

-   Frontend development
-   Backend development
-   API creation
-   Database integration

This is the longest phase in SDLC.

------------------------------------------------------------------------

## 5. Testing

Types: - Unit Testing - Integration Testing - System Testing - User
Acceptance Testing (UAT)

Goal: - Find and fix bugs

------------------------------------------------------------------------

## 6. Deployment

-   Move application to server
-   Configure environment
-   Make it live for users

Types: - Manual deployment - Automated deployment

------------------------------------------------------------------------

## 7. Maintenance

-   Bug fixes
-   Performance improvements
-   Feature enhancements
-   User support

This phase continues throughout the product life.

------------------------------------------------------------------------

## SDLC Models Overview

### Waterfall Model

    Requirement → Design → Development → Testing → Deployment

-   Step-by-step process
-   Best for fixed requirements

### Agile Model

    Plan → Develop → Test → Release → Repeat (Sprint Cycle)

-   Fast delivery
-   Flexible changes
-   Most widely used model

### Iterative Model

    Version 1 → Improve → Version 2 → Improve → Version 3

-   Continuous improvement approach

------------------------------------------------------------------------

## Roles in SDLC

-   Business Analyst → Collects requirements
-   Project Manager → Plans and manages project
-   Developer → Writes code
-   Tester → Ensures quality
-   DevOps Engineer → Handles deployment
-   Support Team → Maintains system

------------------------------------------------------------------------

## Easy Analogy (For Students)

Building a House:

1.  Requirement → What type of house?
2.  Planning → Budget & timeline
3.  Design → Blueprint
4.  Development → Construction
5.  Testing → Quality check
6.  Deployment → Handover
7.  Maintenance → Repairs

------------------------------------------------------------------------

## Short Seminar Definition

> SDLC is a structured process that helps teams plan, build, test,
> deploy, and maintain high-quality software in an organized way.
