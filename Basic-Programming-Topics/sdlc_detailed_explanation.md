# SDLC (Software Development Life Cycle) -- Detailed Explanation

SDLC is a structured process used to build software step by step in an
organized and efficient way.

It answers three key questions: - What to build? - How to build? - How
to maintain it?

In simple words:

> SDLC is the complete journey of software from idea → development →
> testing → deployment → maintenance.

------------------------------------------------------------------------

## 1. Why SDLC is Needed?

Without SDLC: - No proper planning - Confusion in requirements - More
bugs - Delayed projects

With SDLC: - Clear direction - Defined steps - Better quality - Easy
maintenance

------------------------------------------------------------------------

## 2. Main Phases of SDLC

### 1. Requirement Gathering

-   Understand client needs
-   Identify features
-   Prepare requirement documents
-   Business Analyst and stakeholders involved

### 2. Planning

-   Timeline estimation
-   Budget planning
-   Resource allocation
-   Technology selection

### 3. System Design

#### High-Level Design (HLD)

-   Architecture design
-   Module breakdown
-   Database flow

#### Low-Level Design (LLD)

-   API structure
-   Table design
-   Logic flow

### 4. Development (Coding)

-   Frontend development
-   Backend development
-   API creation
-   Database integration

### 5. Testing

-   Unit Testing
-   Integration Testing
-   System Testing
-   User Acceptance Testing (UAT)

### 6. Deployment

-   Move application to live server
-   Configure environment
-   Make it available to users

Deployment can be manual or automated.

### 7. Maintenance

-   Bug fixes
-   Performance improvements
-   Feature enhancements
-   Ongoing support

------------------------------------------------------------------------

## 3. Popular SDLC Models

### Waterfall Model

-   Sequential process
-   Each phase completed before next starts
-   Suitable for fixed requirements

### Agile Model

-   Work divided into small sprints
-   Frequent releases
-   Flexible to changes

### Iterative Model

-   Software built in multiple versions
-   Continuous improvement

------------------------------------------------------------------------

## 4. Roles Involved in SDLC

-   Business Analyst
-   Project Manager
-   Developer
-   Tester
-   DevOps Engineer
-   Support Team

------------------------------------------------------------------------

## 5. Short Seminar Definition

> SDLC is a structured framework that defines the stages involved in
> developing software, ensuring quality, efficiency, and
> maintainability.
