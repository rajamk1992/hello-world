# Software Testing -- Summary Notes

## Types of Testing

### Alpha Testing

-   Done internally within the organization
-   Performed by QA team and developers
-   Goal: Find major issues before releasing to users

### Beta Testing

-   Done by real users before final release
-   Collects feedback and finds real-world issues

### Black Box Testing

-   Tester does not see the code
-   Focus on inputs and outputs
-   Tests functionality and user experience

### White Box Testing

-   Tester knows the internal code
-   Focus on logic, conditions, and code flow
-   Usually done by developers

## Bug Tracking Tool -- Jira

Jira is one of the most widely used tools for tracking bugs and managing
tasks in software projects.

### Why Jira?

-   Create bug tickets
-   Assign issues to developers
-   Track status and progress
-   Add comments, logs, and screenshots
-   Manage sprint tasks

### Typical Bug Workflow in Jira

1.  Open -- Bug created
2.  Assigned -- Assigned to developer
3.  In Progress -- Fix in progress
4.  Fixed -- Developer completed fix
5.  Retest -- Tester verifies
6.  Closed -- Issue resolved

------------------------------------------------------------------------

## Short Seminar Definition

Software testing ensures that an application works correctly, meets
requirements, and is free from major defects before release. Tools like
Jira help track and manage bugs until they are fixed and verified.
