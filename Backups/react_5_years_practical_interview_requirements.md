# React Practical Interview Requirements (5 Years Experience)

## 1. Searchable User List

**Requirement** - Fetch users from:
https://jsonplaceholder.typicode.com/users - Display users in a list -
Add search input to filter users by name - Show loading indicator -
Handle API error - Highlight searched text

**What to Evaluate** - useEffect usage - API handling - State
management - Conditional rendering - Clean component structure

**Bonus** - Debounce search - Memoization - Component separation

------------------------------------------------------------------------

## 2. Todo App with Local Storage

**Requirement** - Add Todo - Delete Todo - Mark as Completed - Store
Todos in localStorage - Filters: - All - Completed - Pending

**What to Evaluate** - Controlled components - State logic -
LocalStorage usage - Code organization

**Senior Bonus** - Edit Todo - Drag & Drop - Keyboard shortcuts

------------------------------------------------------------------------

## 3. Form Handling with Validation

**Requirement** Create Registration Form:

Fields: - Name - Email - Password - Confirm Password - Phone

Validation: - Required fields - Email format - Password match - Phone
validation

**Expected Tools** - Custom validation OR - Formik / React Hook Form

**What to Evaluate** - Form handling - Validation logic - Error
handling - UX awareness

------------------------------------------------------------------------

## 4. Pagination Implementation

**Requirement** - Fetch products from: https://dummyjson.com/products -
Implement pagination - Page numbers - Next / Previous buttons - Page
size selector

**What to Evaluate** - Pagination logic - API state handling - UI
updates - Edge case handling

------------------------------------------------------------------------

## 5. Performance Optimization Task

**Requirement** Given slow code: - Fix unnecessary re-renders - Optimize
filtering - Improve rendering speed

**Concepts to Check** - React.memo - useMemo - useCallback - Key
optimization

------------------------------------------------------------------------

## 6. Context API Task

**Requirement** Build Theme Switcher: - Light / Dark theme - Use Context
API - Apply theme globally

**What to Evaluate** - Context creation - Provider usage - Global state
usage

------------------------------------------------------------------------

## 7. Custom Hook Creation

**Requirement** Create: useFetch Hook

Features: - Fetch data - Loading state - Error handling - Refetch
support

**What to Evaluate** - Hook reusability - Clean abstraction - Code
structure

------------------------------------------------------------------------

## 8. State Management Task (Redux / Zustand)

**Requirement** Build Cart System: - Add item - Remove item - Update
quantity - Show total price

**What to Evaluate** - Store structure - Reducers logic - State
normalization

------------------------------------------------------------------------

## 9. Routing Implementation

**Requirement** Create multi-page app:

Pages: - Home - Products - Product Details - Not Found

Use: - Dynamic routing - Route params

**What to Evaluate** - Routing knowledge - Navigation flow

------------------------------------------------------------------------

## 10. Debugging Task

**Requirement** Fix broken React code:

Common Issues: - State not updating - Infinite useEffect loop - Multiple
API calls - Incorrect dependency array

**Purpose** - Evaluate real debugging ability

------------------------------------------------------------------------
