# 🚀 R Language: The Power Tool for Data Science & Analytics

------------------------------------------------------------------------

## 1️⃣ Introduction to R

R is an open-source programming language used for: - Statistical
computing - Data analysis - Data visualization - Machine learning

Developed in 1993 by Ross Ihaka and Robert Gentleman.

------------------------------------------------------------------------

## 2️⃣ Why R is Important in 2026

-   Data-driven decision making is growing rapidly.
-   High demand for Data Analysts and Data Scientists.
-   Widely used in:
    -   Banking & Finance
    -   Healthcare
    -   Research
    -   Government analytics
    -   Marketing

------------------------------------------------------------------------

## 3️⃣ Key Features of R

-   Open source & free
-   Strong statistical libraries
-   Powerful visualization tools
-   Large community support
-   Cross-platform (Windows, Mac, Linux)

------------------------------------------------------------------------

## 4️⃣ Installing R & RStudio

### Step 1:

Download R from CRAN (Comprehensive R Archive Network).

### Step 2:

Install RStudio (Posit IDE) for better development experience.

Benefits of RStudio: - Script editor - Console - Visualization pane -
Package manager

## 5️⃣ Basic Concepts in R

### Variables

``` r
x <- 10
name <- "Rahul"
```

### Data Types

-   Numeric
-   Character
-   Logical
-   Factor

### Vectors

``` r
marks <- c(80, 75, 90, 85)
```

### Data Frame

``` r
students <- data.frame(
  name = c("A", "B"),
  marks = c(80, 85)
)
```
